## Not done / left
- Not run on a device: Impeller `decodeImageFromPixelsSync` path is untested here (flutter_test uses
  the fallback async path, which works). Perf on phone not measured (docs/03 §4.3 variant B/C if > 8 ms).
- Waterfall history stores already-decimated rows (the controller contract), so after zooming in
  older rows are coarser, after zooming out their missing parts are black (documented in waterfall_model.dart).
- No persistence (shared_preferences) of frequency/mode/levels/colormap yet.
- No SNR/S-meter (needs `calculateVFOSignalInfo` on raw rows — belongs to the DSP side, could be added as a field of FftRow).
- Spectrum/waterfall divider not draggable (fixed 35 %); colour maps are compiled in (no assets/JSON loading).
- Only one VFO (SDR++ supports several).

## For the integrator (contract notes)
- Implement `RadioController` on top of the DSP isolate. `setFftWidth`/`setFftView` are called from layout
  and must not notify synchronously. Rows should cover `centerFrequency + viewOffset ± viewBandwidth/2`;
  `zoomWindow` + `doZoom` from `waterfall_math.dart` are pure and can run in the DSP isolate.
- The UI calls `setTuning(centerFrequency, vfoOffset)`; the DSP VFO must shift by `vfoCenterOffset`
  (depends on mode reference: USB = lower edge, LSB = upper edge).
- `setMode` should reset bandwidth to the mode's (saved or default) value; `DemodParams.clampBandwidth` exists.
