AirSDR for macOS

Installation
1. Drag AirSDR.app onto the Applications shortcut.
2. Open AirSDR from Applications.

First launch
This build is ad-hoc signed and has not been notarized by Apple.
If macOS says Apple could not verify AirSDR:
1. Dismiss the warning.
2. Open System Settings > Privacy & Security.
3. Find the message about AirSDR and click Open Anyway.
4. Confirm that you want to open AirSDR.

This grants an exception for AirSDR. You do not need to disable Gatekeeper.
Apple instructions: https://support.apple.com/102445
