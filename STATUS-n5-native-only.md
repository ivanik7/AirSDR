# N5 native-only receiver status

The production `main.dart` now instantiates ABI v3 `NativeRadioController` on Linux and Android API 26+. A missing/incompatible native library reports a visible unavailable state; `SDR_ENGINE`, the Dart controller/DSP/isolate/audio path, Dart RTL-SDR/HackRF USB drivers and IQ/FFT/demod modules were removed. `DemoRadioController` remains only for widget tests; the ABI-2 JNI path remains for the opt-in N1 diagnostic harness, not for production. Kotlin keeps ownership of the original USB fd; ABI v3 duplicates it. Android USB permission/events and supported-device names, sample-rate/gain metadata moved to `lib/native/`. The foreground service still owns notification/focus lifecycle and Stop.

The pre-deletion inventory was committed independently at `docs/native-n5-inventory.md`. The deletion removes 98 Dart files under `lib/` (25,096 lines, from staged deletions). The remaining production `lib/` contains `main.dart`, `native/` (FFI, controller, catalog, USB channel and settings), `runtime/background_reception.dart`, `platform/linux/native_required_radio_controller.dart` and `ui/` (tuning, spectrum/waterfall, bands, presets, channels, scan, settings and favorites). `lib/n1_qa.dart` is an opt-in diagnostic, not a second production receiver.

## Pending / constraints

The existing RTL-SDR `config.json` stores gain as a tuner-specific *index*, not dB. N5 now persists that index and the selected device name in `native_radio.json`, queries `sdr_v3_rtl_tuner_gains` on the same opened RTL handle, matches the legacy serial to the opened dongle and applies the exact sorted gain entry before the first start. Android re-lists after USB permission so the serial can become visible. A different/unidentified dongle, unavailable tuner table or out-of-range index retains the pending value and the original `config.json`; reception proceeds at the native default gain and status stats include `gainMigration`. A manual gain change explicitly replaces pending migration. The `linux_host_radio.json` dB gain also migrates. Favorites, channels, bands and step data remain in their shared-preferences stores, unchanged. Android API 24/25 installs are no longer supported (minSdk 26).

Android USB OTG, AAudio audibility, physical detach/replug, focus/foreground notification Stop and Activity recreation, and gain restoration on a real Android upgrade remain unverified on a phone; the independent P1 card owns those checks. HackRF hardware, human WAV listening and true WFM stereo are unverified. The operator applied and committed the protected `AGENTS.md` update before the gain migration changes.
